# ShonenChat

Search for shonen anime articles and answer questions and cite back to the document every answer comes from


It will be a Chat agent for Shonen anime geeks


## The problem

When you want to know facts about shonen anime, the data is available in any anime wiki, but it can be buried under many pages; you either know the exact place or you have a vague idea.


## What it covers

It will cover 28 shonen anime, with 65,002 articles, 


## Status

Right now it is in the planning Stage. Nothing works yet; I settled on this idea after 2 rejections.


## How to run

It requires Python 3.13 and uv; clone and then uv run shonenchat
