# ShonenChat

search for shonen anime articles and answer questions and site back to the document every answer comes from

---

It will be a Chat agent for Shonen anime geeks

---

## The problem

when you want to know facts about shonen anime, the data is available in any anime wiki, but it can be burried under many pages, you either know the exact place or you have the vague idea.

---

## What it covers

It will cover 27 shonen animes, with 64,495 articles, 

---

## Status

Right now it is in planning Stage, Nothing works yet, settled on this idea after 2 rejections.

___

## How to run

It requires Python 3.13 and uv, clone and then uv run shonenchat

    git clone git@github.com:example/sitelines.git
    cd sitelines
    uv run sitelines
